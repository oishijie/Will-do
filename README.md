# Will do

## 一、项目简介

**Will do 是一款 Android 智能信息记录助手**
通过截图、图片、文字等方式，识别日常生活中的各类信息，将日程安排、出行信息、取件码等自动整理并记录，配合提醒与实况通知，让信息从看到到记下更省事。

## 二、核心功能

### 信息提取与记录

- **日程安排**：提取时间、地点和事项，支持提醒、重复日程、归档及系统日历同步。
- **取件与取餐**：识别取件码、取餐码及相关地点，集中展示，方便随时查看。
- **出行信息**：识别火车、航班、打车等信息，提取班次、座位、检票口等关键内容。
- **智能识别**：文字与图片走同一套识别协议，配合多模态模型提取结构化信息。

### 悬浮窗与闪记

**闪记**是应用内的轻量记录入口，分为随口记与随手记两类。

- **随口记**：通过首页输入栏或悬浮窗，用文字、语音、图片随时记下临时事项和灵感。
- **随手记**：从系统分享菜单收藏网页、公众号文章、图片或选中的文字，可调用模型生成 AI 摘要；条目保留原文链接，方便回跳查看。
- 随手记可挂到实况通知上，直接在通知里查看内容或移除。
- 配合侧边栏、悬浮球、快捷磁贴等入口，减少应用间切换。
- 通过实况通知展示日程、取件等结果，适配部分厂商胶囊形态。

### 天气

- 查看天气信息，支持定位或选择位置。
- 提供天气预警与风险提示。
- 支持天气实况通知，方便及时了解天气变化。

### 备份与同步

- 连接自己的 WebDAV 服务，进行数据备份与多设备同步。
- 支持本地备份与恢复，方便迁移和保存数据。

## 三、安装与使用

**支持 Android 13 及以上版本。**

### 下载

[点击下载](https://github.com/AIXINJUELUOAI/Will-do/releases)

### 开始使用

1. 下载并安装 Release 页面提供的安装包。
2. 在“功能设置 → 模型与连接”中配置模型服务；截图和图片识别需要支持图片输入的多模态模型。
3. 根据需要授予通知、日历、悬浮窗或无障碍等权限。
4. 通过首页输入栏、悬浮窗或快捷磁贴开始记录；也可从其他应用的分享菜单把内容收藏进随手记。

### 设置导航

设置页按「通用 vs 功能」分组：

- **常规设置**：通用偏好（显示、操作与截图）、主题设置
- **功能设置**：模型与连接、天气、随口记、随手记、悬浮与侧边栏、日程与通知
- **数据**：归档、数据备份
- **其他**：实验室（内含外部调用）、关于软件

## 四、系统适配说明

实况通知会按系统厂商能力自动选择通道：

- **Flyme（魅族）**：实况通知 provider
- **其他系统（含小米 HyperOS）**：原生通知胶囊

小米 HyperOS 灵动岛依赖 LSPosed / Xposed 注入，本项目**不再支持**，相关代码与依赖已移除。

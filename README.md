# Will do

## 一、项目简介

**Will do 是一款 Android 智能信息记录助手**
通过截图、图片、文字等方式，识别日常生活中的各类信息，将日程安排、出行信息、取件码等自动整理并记录，配合提醒与实况通知，让信息从看到到记下更省事。

## 二、核心功能

### 信息提取与记录

- **日程安排**：提取时间、地点和事项，支持提醒、重复日程、归档及系统日历同步。
- **取件与取餐**：识别取件码、取餐码及相关地点，集中展示，方便随时查看。
- **出行信息**：识别火车、航班、打车等信息，提取班次、座位、检票口等关键内容。
- **智能识别**：文字与图片走同一套识别协议，配合多模态模型提取结构化信息。

### 悬浮胶囊与闪记

**悬浮胶囊**是常驻在屏幕边缘的快速记录入口，把日程与闪记收在同一条面板里。

- **把手**：可调大小、主题与停靠侧（左/右）；隐藏后可缩成一条贴边竖线，点按或向内滑动展开。
- **面板**：可调字体大小、可见条数与自动隐藏时长；日程卡片排在闪记卡片之前。
- **输入模式**：点「+」展开输入栏，左侧图标可在**闪记**与**日程**之间切换 —— 写闪记直接存档，写日程则交给识别链路建日程；默认停在闪记。
- **卡片操作**：日程卡片可勾选归档、调色、复制、建闹钟；闪记卡片可复制、建闹钟、归档。
- **唤起方式**：音量键长按与双击共四个槽位，可分别绑定识屏、显示悬浮窗、悬浮窗录音、APP 内录音/笔记等动作。

**闪记**是应用内的轻量记录入口，支持文字、语音、图片与链接。

- 通过首页输入栏或悬浮胶囊，用文字、语音、图片随手记下临时事项和灵感。
- 从系统分享菜单可把网页、公众号文章、图片或选中的文字收藏成闪记，条目保留原文链接，方便回跳查看。
- 支持文件夹分组：可在闪记页新建、重命名、删除文件夹并按文件夹筛选；在某个文件夹里新建的闪记会自动归入该文件夹。
- 删除即归档：左滑、多选、长按与胶囊划走都只是归档，可在「已归档」里恢复；该页也支持清空（彻底删除，含语音与图片文件）。
- 闪记可挂到实况通知上，直接在通知里查看内容或移除。

**电脑访问服务**：开启后，同一 Wi-Fi 下的电脑浏览器即可查看、编辑、删除闪记，手机上的新增与修改也会实时同步过去。

### 天气

- 查看天气信息，支持定位或选择位置。
- 提供天气预警与风险提示。
- 支持天气实况通知，方便及时了解天气变化。

### 备份与同步

- 连接自己的 WebDAV 服务，进行数据备份与多设备同步。
- 支持本地备份与恢复，方便迁移和保存数据。

## 三、安装与使用

**支持 Android 13 及以上版本。**

### 下载

[点击下载](https://github.com/oishijie/Will-do/releases)

### 开始使用

1. 下载并安装 Release 页面提供的安装包。
2. 在“功能设置 → 模型与连接”中配置模型服务；截图和图片识别需要支持图片输入的多模态模型。
3. 根据需要授予通知、日历、悬浮窗或无障碍等权限。
4. 通过首页输入栏、悬浮胶囊或快捷磁贴开始记录；也可从其他应用的分享菜单把内容收藏成闪记。

### 设置导航

设置页按「通用 vs 功能」分组：

- **常规设置**：通用偏好（显示、操作与截图）、主题设置
- **功能设置**：模型与连接、天气、唤起与快捷操作、胶囊外观与展示、日程与通知
- **数据**：日程归档、数据备份
- **其他**：实验室（内含外部调用、电脑访问服务）、关于软件

其中「唤起与快捷操作」管音量键槽位、长按闪记与录音转写；「胶囊外观与展示」管把手外观、面板参数与胶囊内展示的内容。

## 四、系统适配说明

实况通知会按系统厂商能力自动选择通道：

- **Flyme（魅族）**：实况通知 provider
- **其他系统（含小米 HyperOS）**：原生通知胶囊

小米 HyperOS 灵动岛依赖 LSPosed / Xposed 注入，本项目**不再支持**，相关代码与依赖已移除。
